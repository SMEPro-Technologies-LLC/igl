# IGL: Identity Governed Logic

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](./LICENSE)

Canonical repository for the IGL language.

- `igl-v1/` is the canonical v1.0 runtime and the deployed product core. Start here.
- `docs/` holds the specification, architecture, closeout, and assessment.
- `examples/` holds example programs.
- `site/` is the marketing site.
- `archive/` holds prior generations (v0.2 root runtime, and older v1.0 snapshots),
  kept for history and not part of the product line.

CI runs the `igl-v1` suite on every push. The live governed surface is the
`igl-api` Worker under `igl-v1/workers/igl-api`.
