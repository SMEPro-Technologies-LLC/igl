# Brand

Everything here is in `docs/assets/brand/`. The same files are served by the site under `https://id-me.ai/brand/` and used for its favicons and social preview.

## The line

**Governed intelligence. Before execution.**

Use it exactly as written, with both full stops. It is the first line on id-me.ai, the social preview, and the repository preview.

## The logo

| File | Use it for |
|---|---|
| `IGL-horizontal-primary.svg` | Light backgrounds. The default. |
| `IGL-horizontal-reverse.svg` | Dark backgrounds: blue to violet symbol, white lettering |
| `IGL-horizontal-black.svg`, `IGL-horizontal-white.svg`, `IGL-horizontal-blue.svg` | Single color, when the gradient cannot be printed or embroidered |
| `IGL-compact-*.svg` | Below 400 px of display width |
| `IGL-stacked-*.svg` | Square placements, avatars, slides |
| `IGL-symbol-*.svg` | Symbol only: favicons, app icons, 32 px and below |
| `IGL-horizontal-primary-1280.png`, `IGL-horizontal-reverse-1280.png` | When SVG is not accepted (email, some document tools) |
| `IGL-social-share-1200x630.png` | Link previews (Open Graph, Twitter cards) |
| `IGL-repository-preview-1280x640.png` | The GitHub repository social preview |
| `IGL-avatar-white-400.png`, `IGL-avatar-transparent-400.png` | Profile pictures |
| `IGL-Logo-Usage-Guide.pdf` | The two-page size map and clear-space rules |

The SVG lettering is outlined, so no fonts are needed. The PNG exports carry deliberate padding; do not crop or stretch them.

## Colors

| Name | Value | Where |
|---|---|---|
| Blue | `#1455FF` | Start of the symbol gradient |
| Indigo | `#333CFF` | Middle of the gradient |
| Violet | `#713BFF` | End of the gradient |
| Navy | `#12213A` | Lettering on light backgrounds |
| White | `#FFFFFF` | Lettering on dark backgrounds |

## Rules

Keep clear space around the logo equal to the height of the letter I. Never place the primary version on a dark background or the reverse version on a light one. Never recolor the symbol, add shadows or outlines, rotate it, or set it in a different typeface. Pair it with the company name as "SMEPro Technologies" in small capitals when the context needs the parent company; the site footer shows the form.
