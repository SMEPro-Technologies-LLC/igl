# Support

| Need | Where |
|---|---|
| Using the runtime or the contract | [Documentation](https://id-me.ai/#docs), [`docs/`](./docs/), [GitHub Discussions](https://github.com/SMEPro-Technologies-LLC/igl/discussions) |
| A bug in this repository | [Open a bug report](https://github.com/SMEPro-Technologies-LLC/igl/issues/new?template=bug.yml) |
| A security vulnerability | **Not an issue.** See [SECURITY.md](./SECURITY.md) |
| The hosted platform (accounts, keys, tenants, SLAs) | Through the Developer Console at [id-me.ai](https://id-me.ai/#console), or [Contact Sales](https://id-me.ai/#sales) for enterprise plans |
| Conduct concerns | conduct@id-me.ai |

Issues are triaged weekly. Issues with a minimal reproduction and a failing test get fixed first.
